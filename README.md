This project is a Python-based tool for visualizing the performance of the top 10 wide receivers (WRs) in the NFL for a given year. It scrapes data from Pro Football Reference and generates a scatter plot to analyze the relationship between receptions and receiving yards, while also displaying the number of touchdowns (TDs) scored by each player.

Features

Web Scraping: Automatically fetches data for a specific year from Pro Football Reference.

Player Stats: Displays receptions, receiving yards, and touchdowns for the top 10 WRs.

Visualization: 

Creates a scatter plot with:

Player names and their touchdown counts next to each point.

Customizable point colors.

A legend explaining the inclusion of touchdowns.
